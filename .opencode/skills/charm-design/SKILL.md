# Charm Design System

Use this skill whenever creating or modifying UI for this project.

## Visual Direction

Charm design is warm, polished, and friendly.

The overall design should feel:
- Warm
- Premium
- Friendly
- Modern
- Human-designed
- Clean and approachable

Avoid:
- Generic AI-looking interfaces
- Excessive gradients
- Excessive shadows
- Cold corporate styling
- Overly complicated layouts
- Excessive animations

## Color Direction

Use a restrained palette with a maximum of 3 primary colors.

### Primary Action
Use vivid coral for:
- Primary buttons
- Important CTAs
- Active states
- Key interactive elements
- Small highlights

### Background
Use warm cream for:
- Hero sections
- Footer sections
- Large promotional areas

### Neutral
Use soft warm neutrals for:
- Cards
- Panels
- Inputs
- Secondary sections
- Page backgrounds

Keep contrast accessible.

## Typography

Use confident display typography for:
- Hero headings
- Major section headings
- Important marketing statements

Use a clean, highly readable font for:
- Body text
- Forms
- Navigation
- Tables
- Supporting content

Create clear hierarchy between:
- Display heading
- Section heading
- Body
- Caption
- Labels

Avoid excessive font sizes and unnecessary font variations.

## Components

Prefer:
- Pill-shaped buttons
- Pill-shaped filters
- Rounded cards
- Soft panels
- Clean navigation
- Generous whitespace
- Simple icons
- Clear CTAs

Buttons should feel friendly and tactile.

Primary buttons should use coral.

Secondary buttons should use neutral or outlined styling.

## Depth

Use restrained depth.

Prefer:
- Very soft shadows
- Subtle borders
- Layered cream/neutral surfaces

Avoid:
- Heavy drop shadows
- Glassmorphism everywhere
- Strong 3D effects
- Excessive gradients

## Layout

Use:
- Spacious layouts
- Strong visual hierarchy
- Comfortable padding
- Rounded containers
- Clear content grouping

Hero sections should feel visually important without becoming overcrowded.

## Responsive Design

Design mobile-first.

Desktop:
- Spacious multi-column layouts
- Large typography
- Generous horizontal spacing

Tablet:
- Reduce column count
- Maintain comfortable spacing

Mobile:
- Single-column layouts where appropriate
- Large touch targets
- Pill controls should remain usable
- Avoid horizontal overflow
- Keep headings readable
- Maintain visual hierarchy

## UX Principles

Every screen should be:
- Easy to understand
- Easy to navigate
- Visually calm
- Consistent
- Accessible

Prioritize usability over decoration.

## Implementation Rules

Before changing an existing UI:

1. Inspect the existing implementation.
2. Preserve existing functionality.
3. Preserve API behavior.
4. Preserve database behavior.
5. Preserve existing routes.
6. Do not remove working features.
7. Only improve visual design and UX where requested.

Use reusable components instead of duplicated UI.

Maintain consistent:
- Border radius
- Spacing
- Typography
- Button styles
- Colors
- Interactive states

The final interface should look intentionally designed rather than AI-generated.
